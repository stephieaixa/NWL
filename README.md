## ¿Qué es NWL? / What is NWL?

Plataforma interactiva para aprender software profesional de producción audiovisual y eventos en vivo.  
Interactive platform for learning professional software for audiovisual production and live events.

**Metodología / Methodology:** Play to learn — simuladores reales, misiones progresivas, quizzes con feedback y guías de crisis para situaciones en vivo.
